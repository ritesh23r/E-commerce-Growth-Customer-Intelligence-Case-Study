# Sales & Customer Performance Analysis

## Overview

An end-to-end data analytics project analyzing sales performance, customer purchasing behavior, product demand, and regional performance.

## Business Objective

The objective of this project is to identify key revenue drivers and understand customer and product performance across different markets.

The analysis focuses on:

- Sales and transaction performance
- Average Order Value (AOV)
- Product demand and revenue
- Customer purchasing behavior
- Regional performance

## Key Insights

- Total Revenue: 311,111
- Total Transactions: 805
- Average Order Value: 447 
- Active Customers: 267
- Average Customer Spend: 1,165
- Product_3 was the highest revenue-generating  product.
- Product_50 had the highest product demand.
- Italy was the leading customer market.

## Tools Used
- Google Sheet
- SQL
- PostgreSQL
- Power BI

## Project Workflow

**Data Cleaning → Exploratory Data Analysis → SQL Analysis → KPI Analysis → Power BI Dashboard → Business Insights**

## Business Recommendations

- Prioritize inventory for high-demand products.
- Develop retention strategies for high-value customers.
- Focus marketing efforts on high-performing markets.
- Monitor product demand and revenue together to improve product decisions.
